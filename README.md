# RESCAP-MG: Resilient ESS-Supported Adaptive Protection Framework

A comprehensive Python framework for protection and control of inverter-dominated AC microgrids with cyber-resilience capabilities.

## Overview

RESCAP-MG implements an adaptive protection framework for inverter-dominated AC microgrids with:
- **Physics-guided fault detection** and confidence estimation
- **Event-triggered multi-agent coordination**
- **ESS-assisted fault-current support**
- **Cyber-resilient fallback logic**

## Features

- ✅ Adaptive relay coordination
- ✅ High-Impedance Fault (HIF) detection
- ✅ ESS-supported protection
- ✅ Communication-light design
- ✅ Multi-agent coordination
- ✅ Cyber-resilience mechanisms
